    1. 机器人学习领域简介¶

    1.1 问题定义¶

    机器人学习的核心问题是：如何让机器人通过数据学会执行任务？

    传统的机器人控制依赖人工编程——工程师为每个任务编写精确的运动轨迹。这种方式在工厂流水线上运行良好，但面对开放世界中的多样化任务（比如"把红色杯子放到架子上"）则力不从心。

    机器人学习试图从示范数据中自动习得控制策略。一个典型的流程是：

    人类操作员演示任务 --> 收集(图像, 动作)数据对 --> 训练模型 --> 模型预测机器人动作

    1.2 模仿学习 (Imitation Learning)¶

    模仿学习是当前机器人学习的主流范式。核心思路很简单：

    • 输入: 机器人当前看到的图像（通常来自多个摄像头）+ 语言指令（如"拿起杯子"）
    • 输出: 机器人应该执行的动作序列（如关节角度变化、末端执行器位移等）

    模型通过大量人类演示数据学习这种"观察 -> 动作"的映射关系。

    1.3 关键挑战¶

    • 泛化性: 训练时见过"拿红色杯子"，能否推广到"拿蓝色杯子"？
    • 多模态动作分布: 同一个任务可能有多种合理的执行方式
    • 数据效率: 机器人数据采集成本极高
    • 跨机器人迁移: 在一个机器人上学到的知识能否迁移到另一个机器人？

    DreamZero 通过利用大规模视频生成模型的预训练知识来应对这些挑战。

    2. 视觉语言动作模型 (VLA)¶

    2.1 什么是 VLA？¶

    VLA (Vision-Language-Action) 模型是一类将视觉理解、语言理解和动作生成统一在一个模型中的系统。

    传统方案 (分离式):
  感知模块(视觉) --> 规划模块(语言理解) --> 控制模块(动作)
  各模块独立训练，信息传递有损

VLA 方案 (统一式):
  [图像 + 语言指令] --> 单一大模型 --> 动作序列
  端到端学习，信息无损传递

    2.2 VLA 的核心组件¶

    一个 VLA 模型通常包含以下部分：

    1. 视觉编码器: 将摄像头图像转换为特征向量
    2. 语言编码器: 将自然语言指令转换为特征向量
    3. 融合骨干网络 (Backbone): 将视觉和语言特征融合
    4. 动作头 (Action Head): 基于融合特征生成具体的动作序列

    在 DreamZero 中，这些组件对应的代码结构为：

    概念 代码位置
    整体 VLA 架构 groot/vla/model/dreamzero/base_vla.py
    视觉编码器 groot/vla/model/dreamzero/modules/wan_video_image_encoder.py
    语言编码器 groot/vla/model/dreamzero/modules/wan_video_text_encoder.py
    骨干网络 groot/vla/model/dreamzero/backbone/
    动作头 groot/vla/model/dreamzero/action_head/wan_flow_matching_action_tf.py

    2.3 动作空间¶

    DreamZero 预测的"动作"是一个具体的数值向量，包含：

    • 末端执行器位移 (x, y, z 方向的移动量)
    • 末端执行器旋转 (姿态变化)
    • 夹爪开合 (抓取或释放)

    这些数值被组织成 (action_horizon, action_dim) 的张量，其中： - action_horizon = 24：模型一次预测未来 24 步的动作 - action_dim：每步动作的维度（取决于具体的机器人构型）

    3. 世界模型 (World Models)¶

    3.1 核心思想¶

    世界模型是一种能够预测未来状态的模型。给定当前状态和动作，世界模型可以"想象"出未来会发生什么。

    世界模型的"想象"过程:

  当前观察(图像) + 动作 --> 世界模型 --> 预测的未来观察(视频)

    这类似于人类的心理模拟能力——你在伸手拿杯子之前，大脑已经"预演"了手臂的运动轨迹和杯子被拿起的画面。

    3.2 为什么世界模型对机器人有用？¶

    1. 隐含物理理解: 一个能准确预测视频的模型必然理解物体的物理属性（重力、碰撞、刚体/柔体等）
    2. 数据增强: 可以通过"想象"来生成额外的训练数据
    3. 规划: 可以在"想象空间"中评估不同动作方案的效果

    3.3 世界动作模型 (World Action Model, WAM)¶

    DreamZero 提出了 World Action Model (WAM) 的概念——将世界模型和动作策略联合训练：

    • 模型同时学习预测未来视频帧和输出动作序列
    • 视频预测任务迫使模型建立对物理世界的深层理解
    • 这种理解自然地迁移到动作预测中，使得模型具有强大的零样本泛化能力

    4. 扩散模型 (Diffusion Models) 基础¶

    4.1 直觉理解¶

    扩散模型的核心思想可以用一个比喻来理解：

    前向过程 (加噪): 想象一滴墨水滴入清水——墨水逐渐扩散，最终变成均匀的淡色水。

    反向过程 (去噪): 如果你能"倒放"这个过程，就能从一杯淡色水中还原出最初的墨滴形状。

    在数学上：

    前向过程 (训练时):
  干净数据 x0 --> 加入噪声 --> ... --> 加入更多噪声 --> 纯噪声 xT

反向过程 (推理时):
  纯噪声 xT --> 模型去噪 --> ... --> 模型继续去噪 --> 生成数据 x0

    4.2 扩散模型为什么适合机器人？¶

    传统的回归模型在面对多模态分布时表现不佳。例如，绕过障碍物可以从左边绕或从右边绕，回归模型可能预测出"从中间穿过"这种无效动作。

    扩散模型天然地处理多模态分布——它可以从同一个噪声出发，生成左绕或右绕两种合理的轨迹。

    4.3 在 DreamZero 中的应用¶

    DreamZero 使用扩散过程来同时生成： - 视频帧: 预测机器人执行动作后的视觉画面 - 动作序列: 预测机器人应该执行的具体动作

    两者在同一个扩散/去噪过程中联合生成。相关代码位于： - groot/vla/model/dreamzero/modules/flow_match_scheduler.py - groot/vla/model/dreamzero/modules/flow_unipc_multistep_scheduler.py

    5. Flow Matching 技术¶

    5.1 Flow Matching vs. 传统扩散¶

    Flow Matching 是扩散模型的一种现代改进。传统扩散模型需要数百步去噪，而 Flow Matching 构建了一条从噪声到数据的直线路径，大幅减少所需步数。

    传统扩散模型:
  噪声 --弯曲路径(数百步)--> 数据
  每步微小调整，路径不直接

Flow Matching:
  噪声 --直线路径(数十步)--> 数据
  学习速度场，沿最优路径传输

    5.2 数学直觉¶

    Flow Matching 的核心是学习一个速度场 v(x, t)，它告诉你在时刻 t、位于 x 时，应该朝哪个方向、以多大速度移动，才能从噪声到达目标数据。

    训练目标非常简洁：

    损失函数 = || v_模型(x_t, t) - (x_1 - x_0) ||^2

其中:
  x_0 = 纯噪声
  x_1 = 目标数据（视频帧 / 动作序列）
  x_t = t * x_1 + (1-t) * x_0  （线性插值）
  v_模型 = 神经网络预测的速度

    5.3 时间步调度 (Timestep Scheduling)¶

    DreamZero 使用 shift 参数来调整时间步分布，使模型在不同噪声级别上分配不同的计算量。这在代码中对应 FlowMatchScheduler 类：

    # 核心公式（来自 flow_match_scheduler.py）
sigmas = shift * sigmas / (1 + (shift - 1) * sigmas)

    shift 参数控制时间步的非线性映射——较大的 shift 值会让模型在去噪早期（噪声较大时）花费更多步骤。

    6. 视频生成与动作预测的联合学习¶

    6.1 核心洞察¶

    DreamZero 的关键创新在于：视频生成和动作预测共享同一个模型骨干 (Wan2.1-I2V-14B)。

    为什么这样做有效？

    1. Wan2.1 是一个在海量互联网视频上预训练的 140 亿参数视频生成模型
    2. 它已经学会了丰富的视觉世界知识（物体运动、物理规律、空间关系等）
    3. DreamZero 将动作预测"嫁接"到这个视频模型上，复用其世界知识

    6.2 联合训练机制¶

    在训练时，模型同时优化两个目标：

    总损失 = 视频生成损失 + 动作预测损失

视频生成损失: 预测的视频帧 vs. 真实的未来视频帧
动作预测损失: 预测的动作序列 vs. 人类演示的动作序列

    两个任务的梯度流经同一个 DiT (Diffusion Transformer) 骨干网络，形成互利的学习信号：

    • 视频预测迫使模型理解场景中的物理交互
    • 动作预测引导模型关注与控制相关的视觉特征

    6.3 DiT 缓存推理¶

    推理时，DreamZero 使用 DiT 缓存 (--enable-dit-cache) 来加速。原理是：在多步去噪过程中，相邻步之间的 DiT 中间特征变化很小，因此可以缓存并复用部分计算结果。

    这将推理速度从数秒优化到 GB200 上约 0.6 秒。

    6.4 自回归推理 (Autoregressive Inference)¶

    DreamZero 支持自回归推理模式：模型生成一段视频和动作后，将生成的最后一帧作为下一轮的输入，持续生成后续的视频和动作。这使得模型能够处理任意长度的任务。

    代码中的 socket_test_optimized_AR.py 中的 "AR" 即代表 Autoregressive。

    7.3 数据流详解¶

    训练时的数据流:

      LeRobot 数据集
       |
       v
  数据变换 Pipeline (transform/)
  [视频帧采样] --> [图像增强/缩放] --> [动作归一化] --> [语言 tokenize]
       |
       v
  模型前向传播
  [加噪声到视频 latent 和动作] --> [DiT 预测噪声/速度] --> [计算 Flow Matching 损失]
       |
       v
  DeepSpeed ZeRO-2 反向传播 + 参数更新

    推理时的数据流:

      WebSocket 接收观察数据
       |
       v
  编码: 图像 --> CLIP, 文本 --> UMT5, 状态 --> 编码器
       |
       v
  初始化纯噪声 (视频 latent + 动作 latent)
       |
       v
  多步去噪 (Flow Matching, 约 10-50 步)
  [DiT 缓存加速] --> 每步更新 latent
       |
       v
  解码: 视频 latent --> VAE --> 视频帧 (可视化)
         动作 latent --> 动作头 --> 动作序列
       |
       v
  WebSocket 返回动作给机器人控制器

    8. 关键术语速查表¶

    术语 英文 含义
    世界动作模型 World Action Model (WAM) 同时预测未来视频和动作的模型
    视觉语言动作模型 Vision-Language-Action (VLA) 统一处理视觉、语言、动作的端到端模型
    扩散模型 Diffusion Model 通过逐步去噪从噪声生成数据的生成模型
    Flow Matching Flow Matching 学习从噪声到数据的直线传输路径的生成方法
    DiT Diffusion Transformer 使用 Transformer 架构的扩散模型
    VAE Variational Autoencoder 将高维数据压缩到低维 latent 空间的编解码器
    Latent 空间 Latent Space 数据的压缩表示空间，模型在此空间中进行去噪
    动作地平线 Action Horizon 模型一次预测的未来动作步数 (DreamZero 中为 24)
    零样本 Zero-shot 无需在目标任务上额外训练即可完成该任务
    LoRA Low-Rank Adaptation 通过低秩矩阵高效微调大模型的方法
    DeepSpeed ZeRO DeepSpeed ZeRO 分布式训练中的显存优化策略
    Embodiment Embodiment 机器人本体/构型 (如 DROID、AgiBot、YAM)
    DROID DROID 一个大规模多机器人操作数据集
    LeRobot LeRobot HuggingFace 的机器人学习数据格式标准
    Wan2.1-I2V-14B Wan2.1-I2V-14B DreamZero 使用的 140 亿参数视频生成基座模型
    UMT5-XXL UMT5-XXL 用于语言编码的多语言 T5 模型
    自回归推理 Autoregressive Inference 将上一步的输出作为下一步的输入，循环生成
    DiT 缓存 DiT Cache 复用相邻去噪步的中间特征以加速推理
