# 数据变换（Transform）配置索引

## 概述

`transform/` 目录包含 DreamZero 模型特定的数据变换和体型映射配置。这些配置定义了如何将原始数据集样本转换为模型可接受的输入格式，以及如何处理多机器人体型的差异。

## 文件索引

- [base.yaml](base.md) -- 机器人体型标签到投影器索引的映射表（支持 30+ 种机器人）
- [dreamzero_cotrain.yaml](dreamzero_cotrain.md) -- DreamZero 联合训练数据变换与数据整理器

## 数据处理流程

```
原始数据样本
  │
  ├─ 视频变换（裁剪、缩放、颜色增强等）──┐
  ├─ 状态变换（归一化）─────────────────────┤  定义在 data/ 配置中
  ├─ 动作变换（归一化）─────────────────────┤
  └─ 拼接变换（多模态拼接）────────────────┘
                │
                ▼
  DreamTransform（模型特定变换）──── 定义在 dreamzero_cotrain.yaml
    - 语言指令处理
    - 维度填充/截断
    - 体型标签映射
                │
                ▼
  DefaultDataCollator（批次整理）──── 定义在 dreamzero_cotrain.yaml
    - 分词器编码
    - 多视角处理
    - 批次拼接
                │
                ▼
  模型输入张量
```

## 体型映射说明

`base.yaml` 维护了一个从机器人体型标签到投影器索引的映射表。每种机器人使用独立的状态/动作投影器，以处理不同的运动学空间。当前支持包括人形机器人（GR-1）、工业臂（Panda）、双臂平台（AGIBot、YAM）等 30 多种机器人形态。
