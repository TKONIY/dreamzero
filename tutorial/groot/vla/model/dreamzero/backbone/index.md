# `dreamzero/backbone/` -- Backbone 模块

## 模块概述

提供 VLA 架构中的 backbone 组件。DreamZero 使用 IdentityBackbone（透传 backbone），因为其 action_head 已内置完整的视觉编码能力。

## 文件列表

| 文件 | 描述 |
|------|------|
| [`base_backbone.py`](base_backbone.md) | `Backbone` 抽象基类 |
| [`identity.py`](identity.md) | `IdentityBackbone` 恒等 backbone，输出空特征 |

`__init__.py` 文件为空。
